## プレイヤー向け：正常要件・公開前提

## プレイヤー向け：報告候補

範囲、原因、主張3枚と各1–2枚の証拠、修復、再発防止、確認を選ぶ。主張ごとの必要証拠件数を表示する。各主張に根拠1枚以上があれば提出でき、1枚につけられる証拠は計2枚まで。

### 範囲

- 袖SW配下VLAN42の別セグメント通信を対象とし、同一SW内の通信や管理30とは分けて扱う
- 袖SW配下の全通信を対象とし、同一SW内の通信と管理30を含む共通停止として扱う
- 配信サーバを使う全利用者を対象とし、字幕端末と本館確認PCを含むサービス停止として扱う
- 袖SW配下の管理VLAN30を対象とし、字幕VLAN42の上流通信は正常として扱う

### 原因・仮説

- core Gi5 trunkのallowedから42が欠落し、字幕のGW探索が入場判定で破棄された
- D1のGWアドレスが承認値と違い、字幕が必要な上流へ転送する宛先を見つけられなかった
- D1とD2が異なるaccess VLANに属し、字幕系統内のL2通信ができなくなった
- uplinkのケーブルが切れ、物理リンクの停止によって字幕と管理の上流通信が失われた
- 配信サーバのHTTPSサービスが停止し、字幕端末から届いた接続要求へ応答できなかった

### 修復

- 設定・カウンタ・採取を保全し、core Gi5に42を追加して30,42を維持し、字幕と管理の分離を保つ
- 設定・カウンタ・採取を保全し、D1のGWを配信サーバIPへ変更して、trunkとVLANの設定を維持する
- 設定・カウンタ・採取を保全し、uplinkケーブルを交換して、両端のallowed集合と端末設定を維持する
- 設定・カウンタ・採取を保全し、trunkで全VLANを許可して字幕と管理の境界を撤去し、端末IPを維持する

### 再発防止

- trunk両端と必要な全VLANを照合し、各VLANでGW経由の業務通信を受入として、分離条件を維持する
- trunk両端のlink upを受入記録にし、その継続を字幕と管理の到達性判定として、現在のVLANを維持する
- 管理30からの業務通信を受入記録にし、その成功を字幕42の判定にも用いて、現在の端末IPを維持する
- 字幕原稿の文字校正を受入記録にし、表示内容の正しさを上流通信の判定として、ネットワーク設定を維持する

### 確認

- D1/D2からGWのARPと配信TCP443・字幕表示を確認し、同じtrunkの管理30も確認して、分離条件を確かめる
- D1からD2のpingとMAC応答を確認し、同一SW内の成功を上流判定にして、配信HTTPSの追加試験は省略する
- 配信サーバ自己診断と本館PCのHTTPSを確認し、その成功を字幕側の判定にして、袖側の追加試験は省略する
- trunk両端の緑ランプとlink upを確認し、その継続を字幕の判定にして、VLAN別の追加試験は省略する

## 提出後の6段階因果解説
