# NET04 技術引継ぎ：片道の検品票

作者向け。mode/type=network、難易度難、30–45分。食品加工会社の配送センターで検品票を確定できない一群の端末。依頼役・出荷担当の三枝はトラックの積み込みを続けつつ検品の重複確定を避けたい。運用役・向井は冗長経路を残し、返答検査を無効にせず復旧したい。

## 正常要件・公開前提

拠点10.44.16.0/24は業務サーバ10.90.0.20:443へFW-A経由で往復する承認済み運用。FW-Bは切替用に物理接続されているが今回拠点の現用経路ではない。通信量や送信元末尾で経路を振り分けない。IPv4のみ、NAT/ECMP/PBR/VRFなし、経路は表示する有効表の最長一致、同じ長さの競合なし。TTLによるDNS移行問題は扱わない。

FW-A/Bは独立ステートフル装置で状態共有なし。外側（拠点側）から内側（DC側）のTCP443 SYN開始を許可、返答は同一FWに往路SYNを見た状態がある場合だけ許可。DCから来たSYN-ACKを新規開始とは認めない。一般に非対称経路が必ず障害になるとはせず、この装置仕様とログで判断する。FWを無状態化しない。記録は対象試行の5-tuple/初期SYNを全範囲採取し、過去セッションと混ぜない。
