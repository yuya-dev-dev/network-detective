# 調査用BGM

ユーザーの要望によりGoogle Geminiの「音楽を作成」で生成したインストゥルメンタルを使用する。2026-10-05に、ログイン済みのユーザーアカウントで生成。新しい契約や有料購入は行っていない。アカウントの無料・有料区分は未確認。

- 曲名：The Midnight Ledger（生成音源のメタデータ）
- 取得：Geminiの生成結果プレイヤーに表示された音声付きMP4。ブラウザのアセット保存機能で取得。
- 同梱：`public/audio/investigation.mp3`。動画トラックを除き、音声を64kbpsステレオMP3へ変換。約61.7秒、494,488 bytes。
- 生成結果画面：`screenshots/gemini-bgm.jpg`
- 音源はアプリに同梱し、ゲームの実行時に生成サービスへ接続しない。

生成時に送ったのは以下の一般的な音楽指示のみ。非公開のソース、設計書、事件内容、解答は送っていない。

> 昔の携帯ゲーム機の推理アドベンチャーで、資料を読み比べて静かに考える調査場面に流れる、オリジナルのインストゥルメンタルBGMを作成してください。約30～60秒。少し懐かしいサンプラーのエレクトリックピアノ、控えめなシンセパッド、柔らかな低音、さりげないリズム。短調、80 BPM程度。夜の捜査室、好奇心、落ち着いた緊張感、考える楽しさ。読解を邪魔しない繰り返しのある旋律と安定した音量。ボーカル・歌詞・人の声は一切なし。大きな盛り上がり、派手なドラム、効果音、恐怖演出、劇的な終止は避け、ループ再生に向く構成。既存作品のメロディーや特定の曲を再現しないでください。

## 再生（2026-10-07更新）

ユーザーの要望によりBGM・効果音を標準で有効とし、音声ON/OFFボタンを撤去した。従来の音楽ボタン位置にはダーク／ホワイト表示切替を置く。表示選択は音声と独立したlocalStorageキーに保存する。

ブラウザの再生制限に合わせ、最初のユーザー操作内でAudioContext.resumeを呼ぶ。同梱MP3をfetch・decodeAudioDataで取得し、ループ再生する（gain 0.18）。BGMに自作の合成曲は使わない。事件を切り替えても同じ再生を維持する。

操作効果音はWeb Audioの三角波を650Hzから280Hzへ下げ、短い音量包絡で約55msに収めた電子クリック。最大gain 0.055。ボタン、SVG機器、確認済みチェック、選択肢、開閉見出しに同じ音を使い、正誤のヒントを含めない。無効な操作は鳴らさず、連打時は前の効果音を止める。外部取得する音源や生成サービスへの接続は不要。

タブ非表示・pagehide・BGM再生中のContext中断では取得を中断し、AudioContextを解放する。再表示だけでは音を再開せず、次の操作で再開する。再生拒否・音声非対応でもゲームを続行でき、次の操作で再試行する。BGM取得失敗時も効果音とゲーム操作は維持する。

ChromiumのE2Eで初回操作からのBGMと効果音、事件間の継続、停止・再開、キャッシュ済み音源のオフライン再生、再生拒否と非対応時の継続、キーボード・ダイアログ・チェック操作と無効ボタンの扱いを確認する。Windows版Playwright WebKitはAudioContextが利用できないため、この環境から実機Safariでの音声再生を確認したとは扱わない。音量の聴感と実スマホでの再生は未実測。

Service Workerに同梱MP3を含め、オフライン準備完了後は音源も取得済み。効果音は端末内で生成する。音源を含む必須資産合計はビルドの1MB上限で確認する。
