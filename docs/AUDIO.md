# 調査用BGM

ユーザーの要望によりGoogle Geminiの「音楽を作成」で生成したインストゥルメンタルを使用する。2026-10-05に、ログイン済みのユーザーアカウントで生成。新しい契約や有料購入は行っていない。アカウントの無料・有料区分は未確認。

- 曲名：The Midnight Ledger（生成音源のメタデータ）
- 取得：Geminiの生成結果プレイヤーに表示された音声付きMP4。ブラウザのアセット保存機能で取得。
- 同梱：`public/audio/investigation.mp3`。動画トラックを除き、音声を64kbpsステレオMP3へ変換。約61.7秒、494,488 bytes。
- 生成結果画面：`screenshots/gemini-bgm.jpg`
- 音源はアプリに同梱し、ゲームの実行時に生成サービスへ接続しない。

生成時に送ったのは以下の一般的な音楽指示のみ。非公開のソース、設計書、事件内容、解答は送っていない。

> 昔の携帯ゲーム機の推理アドベンチャーで、資料を読み比べて静かに考える調査場面に流れる、オリジナルのインストゥルメンタルBGMを作成してください。約30～60秒。少し懐かしいサンプラーのエレクトリックピアノ、控えめなシンセパッド、柔らかな低音、さりげないリズム。短調、80 BPM程度。夜の捜査室、好奇心、落ち着いた緊張感、考える楽しさ。読解を邪魔しない繰り返しのある旋律と安定した音量。ボーカル・歌詞・人の声は一切なし。大きな盛り上がり、派手なドラム、効果音、恐怖演出、劇的な終止は避け、ループ再生に向く構成。既存作品のメロディーや特定の曲を再現しないでください。

## 再生

タイトルと各画面のBGMボタンからON/OFFを切り替える。初期OFF。ユーザー操作内でAudioContext.resumeを呼び、同梱MP3をfetchで取得してdecodeAudioDataでデコードし、ループ・控えめな音量で再生する。数学的な自作音源は使用しない。タブが非表示になる、画面から離れる、ブラウザが音声Contextを中断する場合はOFFとなり、自動復帰しない。停止時は取得を中断し、音源ノードとAudioContextを解放する。

再生できない場合もゲームは続行でき、ボタンから再試行できる。Chromiumでは実音源の再生、停止、手動再開と通信遮断時の再生を確認。Windows版Playwright WebKitにはAudioContextが存在せず、MP3のHTTP/Blob再生も実デコードに失敗したため、実音源再生の2テストは明示的にスキップする。音声非対応時のゲーム継続と、キャッシュ済みMP3の取得はWebKitでも検証する。これは実機Safariの再生確認ではなく、Safari実機BGMは追加確認として残る。[Playwright公式](https://playwright.dev/docs/browsers#webkit)も、メディア対応がOSに依存しSafari近似にはmacOS上のWebKitを勧めると説明している。

Service Workerの同梱資産に含まれるため、オフライン準備完了後は音源を取得済み。音源を含む必須資産合計はビルドの1MB上限で確認する。端末ごとの音量・OSによる中断挙動は実機で追加確認できる。
