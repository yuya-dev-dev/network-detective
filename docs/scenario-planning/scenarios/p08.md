## プレイヤー向け：依頼と導入

### 依頼

共同劇場の準備資料を扱うポータルで、A団体の担当者から「別団体の未公開資料が開いた」という報告がありました。担当者は自団体の準備を進めるため、通常どおりVPNに接続し、自分の資料も開けています。資料管理者は、各団体から預かった約束を守りつつ、準備を続けてよいか判断できずにいます。認証、接続、要求、本文返却の記録から、確認できた範囲と原因を報告してください。正常時は、自分の団体の非公開資料と明示共有された資料だけを読め、匿名は拒否されます。この条件はVPN内外で共通です。正規の閲覧を戻す手順と、所属の異なる利用者まで含めた確認計画をお願いします。

### 人物と声

- さや：共同劇場で活動するA団体の準備担当、アカウントU17。自分の持ち場を進めたいが、別団体の準備を覗くつもりはない。「私が見てよいもの？」と戸惑う。
- 小田：資料管理者。人を責めるより、団体ごとに預かった約束を守りたい。断定する前に条件を言葉にする。
- 調査員：プレイヤー本人。下部に短い一人称の内心を出す。

### 正常要件・構成

非公開資料は所属団体の一致、又は明示共有がある場合だけ本文を返す。匿名拒否。ネットワークの内部IPは所属の代わりではない。VPN内外に同じ資料条件を適用する。

```text
U17 / A団体 / IdP10.68.10.10
VPNの割当範囲10.68.50.0/24 → ポータル10.68.20.18:443
同じ試験端末の非VPN側10.68.60.23
→ 許可試験LAN10.68.60.0/24 → L3ルータ → 同ポータル
NAT・プロキシなし。APIには実際のpeerIPが見える
```

図は経路仕様を示す。ポータルセッションは送信元IPに固定しない。本人の同じ試験端末で有効な同一セッションを保持し、経路だけを変える比較は許可される。試験用S17の登録主体はU17/A。セッション有効性と正規VPN割当の実測は認証・接続資料に収録する。APIの主体は検証済みサーバセッションから取得し、利用者入力ヘッダ・URLの主体値は信用しない。

全11資料は初期公開・任意順。2026-10-01/JST、時計誤差100ms以内、09:20固定。認証の秘密や資料本文の秘密情報は掲載しない。

### E03 VPN割当台帳〔資料・09:08〜20〕

内心：（同じ名前でも、人物と通信の札は別のものだ。私は台帳の示す接続を読み、人の事情まで勝手に埋めないでおこう。）

内心：（要求には、誰の札で何を求めたかが残っている。私は成功の数字だけを眺めず、その前後の欄も読み終えたい。）

内心：（資料を預かる時の約束も、台帳の一行になっている。私は読めたかどうかだけでなく、扱う条件を丁寧に読もう。）

内心：（内側だからという響きに、少し安心を重ねたかもしれない。私は書いた条件を読み直し、確かめた範囲へ戻ろう。）

## 採点後に表示する解説

VPN中に別団体資料が開いたという申告に対し（E01）、U17の有効なポータルセッションと正規のVPN割当が確認できます（E02/E03）。APIは検証済みのA団体U17としてD204を要求し、8192Bの本文を返しました（E04）。台帳のD204はB団体・非公開で、版とハッシュも一致します（E05）。表示だけの問題や全資料公開では、この組合せを説明できません。

稼働設定とR41の追跡では、VPN範囲に一致したため所有団体比較を省略しています（E06）。非公開資料は団体一致か明示共有が必要という要件に、この例外が反しています（E07）。同じ端末・S17による許可試験LANからは所有比較を行いD204を拒否しており、経路条件との対応も確認できます（E08）。

設定とログを保全し、必要な一時制限の上で例外を無効化し、全要求の所属又は共有を確認するのが修復です。VPN内外で団体内許可・団体間拒否・匿名拒否を組み合わせ、拒否時に本文0で監査が残るか確認します（E07/E08）。確認できた返却は指定期間のD204で、全世界公開や管理権限奪取、返却後の利用までは分かりません（E09/E10）。
