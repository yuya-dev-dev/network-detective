## プレイヤー向け：正常要件・ブラウザの前提

持ち主はログイン後、自分が預けた一冊の引渡し場所を確認フォームから変更できる。閲覧用GETでは変更しない。当日の変更受付は必要で、他人の票や資料へはアクセスできない。今回のowner checkは正常で、匿名要求は401になる。

セッションCookieはhost-only、Secure、HttpOnly、SameSite=Lax明示。対象ドメインはhandoff.book.example.testのみ。別siteのstory-notice.testはこのCookieを読めない。

今回の端末ブラウザは、外部siteからのトップレベルGETナビゲーションではLax Cookieを対象hostに添付する。iframeや画像の要求とは異なる。Cookie値を見せず、session_labelで対応を表示する。GETにOriginヘッダーがないこと自体を異常とは扱わない。Refererは経路の参考情報で、本人意思を証明する唯一の認証手段にしない。CORS許可がなくてもリンク遷移を阻止しない。

HTTPSを使う区間のTLS検証は正常。公開入口の内側には、保護されたHTTP/8080区間がある。外部から業務サーバへ直接侵入する別経路はない。

10:50〜11:20の変更監査・認証監査・保全ブラウザtraceは全件。server_request_idで対応付ける。11:20に全12資料が存在し、任意順に閲覧できる。後の試験も独立した隔離レプリカの固定記録で、プレイヤーによる修復後ログを作らない。

資料時刻（observedAt）は、その資料の状態・範囲を観測した時刻。全件資料は収録終端、複数イベントは最後のイベント以後を示す。個別の出来事の時刻は本文に残し、「取得」は資料を調査へ揃えた時刻を示す。
