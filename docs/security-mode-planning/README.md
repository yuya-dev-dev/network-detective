各稿には導入・結果のセリフ、一人称の内心、全証拠本文、構成図の設計、仮説・報告候補、必要証拠件数、採点、誤答説明、ヒント、用語辞典を用意しています。これらの多くは作者向け資料に含まれるので、プレイヤーは下記の原稿を開かずにお待ちください。
