# 通信捜査室

スマートフォンのブラウザで遊ぶ、日本語のネットワーク障害調査ゲーム。第1事件のみを実装しています。主人公の一人称で依頼を受け、資料と診断結果を読み、仮説を整理して調査報告を提出します。

専用のタイトル画面から捜査を始めます。雨の夜の都市を描いたタイトル背景と、黒・チャコール・白を基調にした現代的な画面です。調査中は下部の吹き出しに主人公の心の声を表示します。

## 起動

Node.js 26で開発・検証しています。依存関係はlockfileに固定しています。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開いてください。開発サーバーではService Workerを登録しません。

## 遊び方

1. タイトルの「捜査を始める」から一覧を開き、「依頼を開く」で背景と依頼を読む。
2. 「構成／証拠／仮説／報告」のタブを自由に行き来する。
3. 資料を開き、固定診断を選ぶ。各証拠の横の「確認済み」チェックボックスで、読んだ内容の確認を記録する。資料を開くだけではチェックされない。
4. 仮説を「未検証／有力／除外」に分類し、証拠を支持・反証として関連付ける。
5. 原因や対策と、3枚の主張・各1〜2件の証拠を報告する。各主張には必要な証拠数（1件または2件）が表示される。必要数に届かなくても1件以上あれば提出できるが、得点は根拠の成立に応じて決まる。補足を含め、1枚あたり最大2件まで選べる。
6. 提出後に得点と解説を読む。再挑戦は別の試行として記録する。

用語辞典と3段階のヒントを利用できます。ヒントで減点しません。診断は架空環境の固定記録を表示し、実際のネットワークへの接続や設定変更は行いません。

調査用インストBGM「The Midnight Ledger」を同梱しています。初期状態はOFFで、明示的にONにすると約62秒の曲をループ再生します。画面を非表示にする、またはページを離れると停止し、戻っても自動では再開しません。

構成図は全体を小さく表示し、「拡大して見る」で倍率を変えて縦横にスクロールできます。機器をタップすると詳細を開きます。仮説の説明・証拠と報告の選択肢は、必要な項目を開いて確認します。報告を閉じても選択内容は見え、未入力で確認しようとすると該当項目を開きます。

[各画面のサンプル一覧](docs/screenshots/compact/index.html)は390×844pxで撮影しています。結果はネタバレを避けて得点部分だけ表示しています。本番プレビューを起動して `npm exec tsx -- scripts/capture-screens.ts` を実行すると再撮影できます（既定のURLは `http://127.0.0.1:4175`、変更は `PREVIEW_URL`）。

## 保存とオフライン

操作ごとに、このブラウザのlocalStorageへ保存します。同じ端末・同じブラウザ・同じ配信URLで続きから遊べます。ブラウザのデータ削除や保存領域の消去により記録は失われます。保存できない場合は通知し、その画面では続行できます。

以前のピン留め記録は「確認済み」へ引き継ぎます。主張が0〜2枚の旧下書き・提出済み記録も読み込めますが、新しく提出する報告には3枚の主張が必要です。

```sh
npm run build
npm run preview
```

本番ビルドをHTTPSまたはlocalhostで開き、一覧の「オフライン準備完了」を確認すると、第1事件をBGMも含めてオフラインで遊べます。初回のオフライン起動は対象外です。静的配信は `dist/` 全体を同じディレクトリへ配置してください。サブディレクトリ配信にも対応します。

更新は調査中に強制適用しません。新しいバージョンがあるときは、一覧の「保存して更新する」から適用します。ゲームを開いている他のタブを閉じてください。

## 検証

```sh
npm run validate
npm run typecheck
npm test
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

Linuxのブラウザ実行に必要なOSライブラリは `npx playwright install --with-deps chromium webkit` で導入できます。

単体テストは採点、状態遷移、シナリオ検証、保存を確認します。E2EはChromium・WebKitで通しプレイ、戻る・再読み込み、複数タブ、幅360〜430px、オフライン、更新を確認します。

ユーザーが自身のスマートフォンで第1事件を最後まで遊び、100点の結果と読みやすさを確認しました。端末名・OS・ブラウザの情報は未記録です。iPhone SafariとAndroid Chromeの両方を実測した記録としては扱いません。
